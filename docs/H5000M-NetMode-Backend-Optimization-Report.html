4后端架构

5切换状态机（以代码为准）

任一阶段失败/超时 → ROLLBACK → 恢复 IPv4/IPv6/路由/metric/policy，防重复回滚，终态写入状态文件。

6性能优化

固定等待 → 条件等待

# 旧：操作 → sleep 1 → 查询 → sleep 1 → 操作
# 新：操作 → 条件检测 → READY → 立即继续
           └ NOT READY → 短间隔（≤1s）轮询 → 超时（15s/20s/60s 预算）→ 失败

ubus / fork 调用（静态分析）

  • 状态轮询热路径：每轮数百次 fork + 多次 ubus → 快照命中 0 次子进程（TTL 3s，代次标记 gen:applied_mode）。
  • 保留 ubus 仅 3 类：每接口 up/available/pending、无线状态、关联列表，均 5s 有界。
  • 路由操作：ip 派生 → netlink（RTM_NEWROUTE + NLM_F_CREATE|REPLACE）。
  • 状态文件：一次 kv 读复用；写路径仅替换点名键。

探测并行化

              ┌─ ICMP A ─┐
WAN ── 绑定 ────┼─ ICMP B ─┼→ 线程并行 → 任一成功早退
              ├─ DNS ────┤
              ├─ TCP ────┤
              └─ Gateway ─┘

7IPv4 / IPv6 同 WAN 保证

commit_family：先提升目标（10）再降旧主（50），无空窗；分裂由 reconcile 修复，rollback 仅当旧主仍可用时执行。

8可靠性链路

参数校验 → 目标检查 → 超时/有限重试 → 切换 → 业务验证 → 失败 → ROLLBACK
                                                              └→ 防重复回滚 + 错误码 + 日志
  • 并发控制：mkdir 锁 + pid 文件 + /proc 存活判定，worker 排他；请求排队 rc=3。
  • 健康门限：连续失败 streak≥3 才降级，unknown 不累加，避免单次抖动触发切换。
  • 探测绑定 WAN：SO_BINDTODEVICE，杜绝探测流量走错出口误判。
  • 探测目标国内化：223.5.5.5 / 119.29.29.29、IPv6 2400:3200::1 / 2402:4e00::。
